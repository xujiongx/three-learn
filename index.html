学习方法

不要一上来就抄完整项目

1

先建立最小闭环

Three.js 再复杂，底层也是：Scene（舞台）装物体， Camera（眼睛）决定视角，Renderer（画笔）画到画布。 第一课只做这件事。

2

一次只加一个概念

灯光、控制器、模型加载、粒子……按顺序叠上去。每课页面右上角有「概念说明」， 进去先看，再操作 3D 场景。

3

改参数，再重写

打开 main.js，至少改 3 个数字（颜色、位置、速度）。然后合上参考， 凭记忆重写一遍。这比收藏十篇教程有效。

全程会反复碰到的词

Mesh
可渲染物体 = 几何体 Geometry + 材质 Material
世界坐标
默认右手系：+X 右，+Y 上，+Z 朝向你
弧度
rotation 用弧度，不是角度。90° = Math.PI / 2
addons
OrbitControls、GLTFLoader 等官方附加模块，需单独 import

基础课 · 01 → 05

把「能显示」练成「能控制」

下面每一章都先讲清楚「这一步解决什么问题」，再给你打开对应案例。请按顺序学，跳课容易卡在黑屏或看不见模型。

第 1 步 · 看见东西

三大件：Scene + Camera + Renderer

网页上的 3D 并不是魔法：你创建场景，把方块放进去，架好相机，再让渲染器每秒画几十次。 MeshBasicMaterial 先不受灯光影响，保证你一定能看见，建立信心。

  • aspect 必须跟窗口宽高比一致，否则画面拉伸
  • 改了相机参数要调用 updateProjectionMatrix()
  • 忘记 scene.add(mesh) = 永远看不见

第 2 步 · 让它变立体

灯光与 PBR 材质

换成 MeshStandardMaterial 后如果全黑，通常不是坏了，而是场景里没有灯。 环境光负责暗部不死黑，平行光负责立体明暗；metalness / roughness 决定塑料还是金属。

  • 阴影要渲染器、灯光、投射物、接收面四处配合
  • 地面 Plane 默认朝 Z，要旋转成水平才像地板

第 3 步 · 自己转着看

OrbitControls 与 Group

静态视角很快不够用。控制器让你拖拽环绕； Group 则让你把多个物体当成一个整体转。之后太阳系、展台都靠这个思路。

  • 开了阻尼必须每帧 controls.update()
  • 控件来自 three/addons，路径写错会导入失败
03 轨道控制器 拖拽、缩放、看网格辅助 进入 →

第 4 步 · 加载别人的模型

包围盒：居中与统一缩放

业务项目里很少手写几何体，多数是加载 .glb。不同软件单位差十万八千里， 所以加载后要：算 Box3 → 移到原点 → 缩到统一大小 → 放回地面。

  • 本课用程序化机器人演示同一套后处理
  • 真实项目把回调里的模型换成 GLTFLoader 结果即可
04 模型加载流程 看机器人挥手与居中逻辑 进入 →

第 5 步 · 一次画很多东西

粒子：BufferGeometry 批处理

一千个 Mesh 会很卡；一个 Points 挂着大数组却很轻松。 星空、雪、频谱柱都是这条路。记住改了 TypedArray 要 needsUpdate = true。

  • AdditiveBlending 适合发光叠加
  • 这是后面「音频可视化」的前置课

练手坊 · P1 → P10

概念齐了，开始做完整小作品

练手按难度递进：先展台与太阳系（巩固变换），再交互与游戏，最后 Shader 与作品集叙事。 建议每做一个，就在笔记里写「我用到了哪几课的概念」。

入门线 P1–P3：展台、太阳系、骰子。目标是独立拼出「能演示」的东西。

进阶线 P4–P6：产品热点、第一人称、音频粒子。目标是 UI + 3D + 浏览器 API 协作。

挑战线 P7–P10：跑酷、可视化、水面 Shader、作品集房间。目标是完整体验与表达。
